Image-to-Markup / im2latex · 2016–2017 年研究

从图像恢复
LaTeX 与 HTML

让神经网络从图像中恢复内容和布局，生成结构化标记。IM2LATEX-100K 为其中的数学公式识别任务提供公式图片与 LaTeX 源码配对数据。

原始研究 · 2016。 Yuntian Deng、Anssi Kanervisto 与 Alexander M. Rush 在 What You Get Is What You See: A Visual Markup Decompiler 中介绍 IM2LATEX-100K，并研究图像到 LaTeX 和 HTML。后续 ICML 2017 论文由 Yuntian Deng、Anssi Kanervisto、Jeffrey Ling 与 Alexander M. Rush 完成。

研究内容

恢复图像背后的结构

图片转 LaTeX 与数学公式识别

数学公式包含上下标、分式等二维结构。原始模型结合卷积图像编码器、行编码器与带注意力的循环解码器，根据公式图片逐步生成 LaTeX 标记。

模型从配对数据中学习图像到标记语言的映射；目标是生成能够重现输入公式图像的源码。阅读 2016 年原文。

由粗到细的注意力

ICML 2017 论文进一步研究图片转 LaTeX，先选择图像中的支持区域，再进行细粒度注意力计算，以降低视觉注意力的计算开销。

论文评估印刷公式识别，并通过单独的合成手写数据研究向手写公式识别的迁移。

图像到标记语言

从网页图像生成 HTML

2016 年的工作同时研究 LaTeX 和 HTML，展示同一种神经建模思路如何学习不同标记语言。

HTML 实验使用 100,000 个合成片段及其网页渲染图像，包含嵌套布局、相对位置和文字。模型从图像学习恢复 HTML，研究如何重建页面元素及其空间关系。具体数据生成方式与实验结果见原始论文；代码仓库保留合成 HTML 示例。

公式识别数据集

IM2LATEX-100K

公式来自 Cornell KDD Cup 收录的 arXiv 科学论文 LaTeX 源码，经渲染后与源码组成图像—公式对，用于训练和评估数学公式识别模型。

下载前请核对原始归档、项目托管原始与处理文件及 Hugging Face 导出的数据划分和预处理。
