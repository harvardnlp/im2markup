IM2LATEX-100K

Mathematical expression images and LaTeX source, introduced by Yuntian Deng and collaborators in the Image-to-Markup research.

Research citation: Yuntian Deng, Anssi Kanervisto, Jeffrey Ling, and Alexander M. Rush · ICML 2017

Origin and attribution.

IM2LATEX-100K was introduced in Deng, Kanervisto, and Rush’s 2016 visual markup decompiler paper and described in the 2017 ICML paper by Deng, Kanervisto, Ling, and Rush. The original formulas were extracted from arXiv LaTeX sources in the Cornell KDD Cup collection and rendered as images.

The original Zenodo archive was prepared and deposited by coauthor Anssi Kanervisto; its displayed publication date is 21 June 2016. The project’s code repository provides preprocessing, training, and evaluation.

Using a mirror or processed version? Please cite the original research paper below and identify the distribution you used. A new file format, hosting location, or rerendering should retain the original dataset provenance; additional contributions can be credited alongside it.

Processed files

The preprocessing pipeline crops images, downsamples and pads them for batching, and tokenizes or normalizes formula targets. Training and validation are filtered; the test list is converted to the processed format without filtering.

  • formula_images_processed.tar.gzCropped, downsampled and padded expression images

  • im2latex_validate_filter.lstProcessed validation list · 8,370 records

Reproducibility

Before training or comparing results.

Keep formula indices and newline handling intact

Raw split files point into the formula list by zero-based line index. Read the list with explicit LF newline handling, as documented in the original archive. Do not delete empty normalized targets or treat every line as a valid rendered sample without checking the accompanying split and image.

Report preprocessing and evaluation choices

Record the dataset distribution, revision or file hashes, formula normalization, image preprocessing, and split sizes. Different LaTeX strings can render the same expression. The original code provides both text-based and rendered-image evaluation; report the metric you actually use.

Distinguish printed and handwritten data

IM2LATEX-100K contains rendered printed expressions. The separate handwritten archive contains synthetically generated handwritten expressions; it should not be described as a collection of human handwriting. The ICML paper documents the transfer experiments and their evaluation setting.

Source licenses and intended use

The original dataset archive declares CC0 1.0. The model code is MIT-licensed; that is a separate license. Consult the specific release’s documentation when redistributing processed or handwritten data. The data is a research resource for mathematical-expression recognition; its rendered scientific expressions do not represent the full range of real-world images or handwriting.

Citation

Cite the original work.

If you use IM2LATEX-100K, its processed versions, or the Image-to-Markup model, please cite the ICML 2017 paper and identify the exact data release and preprocessing you used. When using a derivative, credit its additional contribution alongside the original dataset.
